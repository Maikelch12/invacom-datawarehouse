# \# Invacom Data Warehouse

# 

# Proyecto académico desarrollado para el curso de Minería de Datos de la Universidad Técnica Nacional, Sede Regional de San Carlos, durante el III Cuatrimestre de 2026.

# 

# \## Descripción del proyecto

# 

# El proyecto consiste en el desarrollo de una solución de inteligencia de negocios para Invacom, orientada al análisis de información comercial y logística mediante un Data Warehouse y la implementación de indicadores gerenciales en Power BI.

# \## Proyecto 1: Data Warehouse

# 

# Diseño e implementación de un almacén de datos mediante un modelo dimensional de esquema estrella.

# 

# \- Extracción de datos desde PostgreSQL.

# \- Procesamiento y transformación mediante Apache Spark (PySpark).

# \- Almacenamiento de información en SQL Server.

# \- Implementación de siete dimensiones y dos tablas de hechos.

# \- Procesamiento de 830 pedidos y 2.155 líneas de venta.

# \- Validación de datos y análisis de indicadores comerciales.

# 

# \## Proyecto 2: Visualización y KPI gerenciales

# 

# Desarrollo de un informe interactivo en Power BI conectado al Data Warehouse implementado en el proyecto 1.

# 

# Los indicadores fueron definidos mediante la metodología SMART y validados mediante consultas SQL.

# 

# | KPI | Indicador | Meta | Resultado |

# |---|---|---|---|

# | K1 | Crecimiento interanual de ventas | ≥ 15 % | 133,44 % |

# | K2 | Variación mensual de ventas | ≥ 0 % | 18,07 % |

# | K3 | Ticket promedio | ≥ 1.500 | 1.525,05 |

# | K4 | Clientes recurrentes | ≥ 90 % | 95,10 % |

# | K5 | Cumplimiento de entregas | ≥ 95 % | 95,43 % |

# | K6 | Tiempo promedio de despacho | ≤ 8 días | 8,49 días |

# | K7 | Tasa de descuento | ≤ 6 % | 6,55 % |

# | K8 | Flete sobre ventas | ≤ 5 % | 5,13 % |
